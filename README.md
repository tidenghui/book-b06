# 药碗与刀

> 她蹲在墙头数他咳血，他在朝堂提刀杀人——满京等着她守寡，她等的是抄家圣旨。

**题材**：古言 · 宅斗 · 权谋 · 先婚后爱　**作者**：灯下人　**12 章 · 36,650 字**

大婚夜，庶女沈知意被嫡姐当众退婚，反手掏出先帝密旨，指名嫁病秧子九王。满京等她守寡，她每天端药碗蹲墙头数他咳几声、吐几口血，硬把卧床等死的男人喂成提刀上朝的铁人。她用庶女手段清王府烂账、拔暗桩、斗仇家，终于在九王大限那日看他朝堂斩了毒害先帝的真凶——她的嫡母。密旨背面浮出一行字：九王缉凶有功，庶女封一品诰命，将军府满门抄没。药碗换交杯盏，墙头加高三尺。
